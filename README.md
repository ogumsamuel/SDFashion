# SD Fashion

SD Fashion is a mobile fashion shopping application built with React Native, Expo, and TypeScript.

## Features

- User authentication
- Fashion product browsing
- Product categories
- Product details
- Wishlist
- Shopping cart
- Checkout
- Order management
- Firebase integration
- Supabase integration
- Paystack payment integration

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- Firebase
- Supabase
- Paystack
